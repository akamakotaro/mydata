# ☕️ Sleep Guard — Mac のスリープ防止 command ファイル

ダブルクリックするだけで **Mac をスリープさせない** ようにする `.command` ファイルです。
タイマーで時間を指定でき、残り時間は**1 秒ごとにリアルタイムでカウントダウン**表示されます。
時間が来ると自動的にスリープ防止を解除し、通知を出します。

macOS 標準の `caffeinate` コマンドを使うので、**追加インストールは不要**です。

```
  ☕️  Sleep Guard v1.0.0
      Mac をスリープさせないタイマー（caffeinate ラッパー）

  ▶ 1時間30分 のあいだスリープを防止します（終了予定 15:42:10）

  残り時間  01:23:45  ████████░░░░░░░░░░░░░░░░░░░░   7%
  終了予定  15:42:10   (経過 00:06:15)
  状態      ☕️ スリープ防止中  ディスプレイ: 常時オン
  操作      [q] 終了   [p] 一時停止/再開   [+] 15分延長   [-] 15分短縮
```

## 使い方

### 1. ダブルクリック（いちばんかんたん）

`sleep-guard.command` をダブルクリックするとターミナルが開き、メニューが表示されます。

```
    1) 15 分        5) 3 時間
    2) 30 分        6) 8 時間
    3) 1 時間       7) 無制限（手動で終了）
    4) 2 時間       8) 自分で入力（例: 90 / 1h30m / 45s）
```

番号を選ぶ → ディスプレイも消灯させないか選ぶ → カウントダウン開始、という流れです。

> **初回だけ**「開発元が未確認のため開けません」と出ることがあります。
> その場合は Finder で **右クリック →「開く」→「開く」** を選ぶと以後は普通に起動できます。

### 2. ターミナルから（時間を直接指定）

```bash
./sleep-guard.command            # メニューから選ぶ
./sleep-guard.command 90         # 90 分
./sleep-guard.command 2h         # 2 時間
./sleep-guard.command 1h30m      # 1 時間 30 分
./sleep-guard.command 45s        # 45 秒
./sleep-guard.command inf        # 無制限（手動で終了するまで）
./sleep-guard.command 3h -n      # ディスプレイの消灯は許可（システムのスリープのみ防止）
./sleep-guard.command --help     # ヘルプ
```

時間の指定は `90`（数字だけなら分）、`2h` / `30m` / `45s` の組み合わせ、
`1時間30分` のような日本語表記にも対応しています。

実行権限がない場合は一度だけ次を実行してください。

```bash
chmod +x sleep-guard.command
```

## 実行中のキー操作

| キー | 動作 |
| --- | --- |
| `q` | 終了（スリープ防止を解除） |
| `p` | 一時停止 / 再開（残り時間が止まります） |
| `+` | 残り時間を 15 分延長 |
| `-` | 残り時間を 15 分短縮（最短 1 分は残ります） |
| `Ctrl-C` | 強制終了（この場合もスリープ防止は必ず解除されます） |

## 機能

- ⏱ **タイマー** — プリセット（15 分〜8 時間）／自由入力／無制限モード
- 🔴 **リアルタイムなカウントダウン** — 残り時間・進捗バー・進捗率・終了予定時刻・経過時間を毎秒更新
- 🖥 **ディスプレイ消灯の制御** — 画面も点けたままにするか選べます
- ⏸ **一時停止・時間の増減** — 実行中にキー 1 つで調整
- 🔔 **終了通知** — 時間が来ると macOS の通知センターに通知（サウンド付き）
- 🧹 **確実な後始末** — 終了・Ctrl-C・ウインドウを閉じた場合も `caffeinate` を必ず停止
- 🪟 **ウインドウタイトルに残り時間** — 他の作業中でもタブを見れば残りが分かります

## しくみ

macOS 標準の `caffeinate` をバックグラウンドで起動し、スクリプト側でタイマーを管理しています。

| 指定 | 意味 |
| --- | --- |
| `-i` | システムのアイドルスリープを抑止 |
| `-s` | 電源アダプタ接続時のシステムスリープを抑止 |
| `-d` | ディスプレイのスリープ（消灯）を抑止 ※`--no-display` を付けると使いません |

タイマーが終わる（または `q` / `Ctrl-C`）と `caffeinate` を停止し、Mac の設定は元どおりに戻ります。
**システム設定を書き換えることは一切ありません**（プロセスが動いている間だけ効きます）。

## 注意事項

- 対応 OS は **macOS のみ**です（`caffeinate` を使うため）。他の OS では起動時に終了します。
- **バッテリー駆動時**は、Apple の仕様上ふたを閉じるとスリープします（`caffeinate` では防げません）。
- ふたを閉じたまま作業させたい場合は、電源アダプタ＋外部ディスプレイ接続などの環境が必要です。
- スリープ防止中は消費電力が増えます。作業が終わったら `q` で終了してください。
- ターミナルのウインドウを閉じるとスクリプトも終了し、スリープ防止も解除されます。
